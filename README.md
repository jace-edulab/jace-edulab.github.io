# 전북AI융합교육연구회 JACE

교사가 직접 만든 AI 수업 도구로 수업과 평가를 바꾸는 교과별 실천 연구 모임의 홈페이지입니다.

- 사이트: https://jace-edulab.github.io/
- 로그인·회원·대화: Firebase (Authentication, Realtime Database)
- 자료실 서버: `server/Code.gs` (Apps Script 웹 앱, 구글 시트·드라이브)

## 사용 조건
교육용(비영리 수업·연구·연수)은 출처를 밝히면 자유롭게 쓸 수 있습니다. 상업용 사용과 고친 판의 무단 배포는 금지합니다. 자세한 내용은 [LICENSE](LICENSE)를 보세요.
